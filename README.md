# Stacklane

Stacklane provides stable hierarchical local hostnames and conflict-free standard ports for parallel Docker Compose stacks and Git worktrees.

Planned addresses follow the form:

```text
feature-a.curri.stacklane.test
postgres.feature-a.curri.stacklane.test:5432
nats.feature-a.curri.stacklane.test:4222
```

## Status

Early design and implementation.
